# Enterprise Decision Intelligence & Risk Analytics Platform

A PostgreSQL-powered Business Intelligence platform built with Streamlit and Plotly.

## Features

- Executive Command Center
- Decision Intelligence
- Risk Intelligence
- Financial Performance
- Project Performance
- Workforce Intelligence
- Executive Insights
- Warehouse Explorer
- SQL Query Workbench

## Tech Stack

- PostgreSQL
- SQL
- Python
- Streamlit
- Plotly
- Pandas
- SQLAlchemy

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Database

Configure:

```text
.streamlit/secrets.toml
```

with your PostgreSQL settings.
